# Página /contato — Formulário de Demonstração

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar a página `/contato` com formulário validado (vee-validate + zod), API route POST e feedback visual de sucesso/erro.

**Architecture:** Página Vue em `app/pages/contato.vue` com lógica inline usando `useForm` do vee-validate. RNavbar recebe prop `minimal` para esconder navegação. API route em `server/api/contato.post.ts` retorna `{ success: true }`.

**Tech Stack:** Nuxt 4, Vue 3, vee-validate 4, @vee-validate/zod, zod, shadcn-nuxt (Input, Label, Select, Checkbox, Toast)

<script setup lang="ts">
import { useForm } from 'vee-validate'
import { toTypedSchema } from '@vee-validate/zod'
import { z } from 'zod'

useHead({ title: 'Fale com a gente — Rumo' })

const schema = z.object({
  nome: z.string().min(2, 'Nome obrigatório'),
  email: z.string().email('E-mail inválido'),
  celular: z.string().regex(/^\d{11}$/, 'Celular deve ter 11 dígitos com DDD'),
  empresa: z.string().optional(),
  segmento: z.string().min(1, 'Selecione um segmento'),
  investimento: z.string().min(1, 'Selecione uma opção'),
  aceitaWhatsapp: z.boolean().optional(),
  aceitaTermos: z.literal(true, {
    errorMap: () => ({ message: 'Você precisa aceitar os termos' }),
  }),
})

const { handleSubmit, isSubmitting, defineField, errors } = useForm({
  validationSchema: toTypedSchema(schema),
  initialValues: {
    nome: '',
    email: '',
    celular: '',
    empresa: '',
    segmento: '',
    investimento: '',
    aceitaWhatsapp: false,
    aceitaTermos: false as true | false,
  },
})

const [nome, nomeAttrs] = defineField('nome')
const [email, emailAttrs] = defineField('email')
const [celular, celularAttrs] = defineField('celular')
const [empresa, empresaAttrs] = defineField('empresa')
const [segmento] = defineField('segmento')
const [investimento] = defineField('investimento')
const [aceitaWhatsapp] = defineField('aceitaWhatsapp')
const [aceitaTermos] = defineField('aceitaTermos')

const submitted = ref(false)
const { toast } = useToast()

const onSubmit = handleSubmit(async (values) => {
  try {
    await $fetch('/api/contato', { method: 'POST', body: values })
    submitted.value = true
  } catch {
    toast({
      variant: 'destructive',
      title: 'Erro ao enviar',
      description: 'Tente novamente ou entre em contato pelo e-mail admin@userumo.com.br',
    })
  }
})
</script>
